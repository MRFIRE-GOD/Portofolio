1Variabler og print

  • print("Hei") viser noe på skjermen. Tekst står i anførselstegn.
  • En variabel er en boks med navn. = betyr «legg verdien til høyre i boksen til venstre».
  • En boks kan få nytt innhold: poeng = 10, så poeng = 15 → 15.
  • Tekst + variabler: print("Jeg er", alder, "år") (komma gir mellomrom automatisk).
  • f-streng: print(f"Det er {dager_igjen} dager igjen til {fag}-eksamen")

4for-løkker

  • for temp in temps: – temp får ett og ett element.
  • range(start, stopp, steg). Stopp er ikke med → skriv siste tall + 1.
    • range(7, 40, 2) → 7, 9, …, 39
    • range(20, 61, 5) → 20, 25, …, 60
    • range(10, 0, -2) → 10, 8, 6, 4, 2
    • Steg 1 er standard: range(1, 11) = 1…10
  • Hver runde legger Python neste tall i variabelen og kjører koden under. Regning inni løkka bruker verdiene som ligger i boksene akkurat nå.
  • Iterasjonsnummer: nr = 1 før løkka, nr = nr + 1 inni.
  • Oppsamling: total = 0 før løkka, total = total + temp inni.
Regelen: det som står fast → før løkka. Det som endrer seg → variabelen i for-linja. Regningen → inni løkka.

5Funksjoner

  • def navn(inn-argumenter): … return svar. Funksjonen er en maskin: tall inn → regner → svar ut.
  • Funksjonen gjør ingenting før du kaller den: resultat = dobbel(5).
  • Argumentene fordeles etter plass: trapes(5, 3, 7) → a=5, b=3, h=7.
  • return bytter ut kallet med svaret: print(trapes(5, 3, 7)) → print(28.0).
  • Variabler inni funksjonen (som a) finnes ikke utenfor.

Funksjon i løkke – eksempelet å se på når du står fast:

def trapes(a, b, h):
    return h * (a + b) / 2

for b in range(3, 13):
    print(trapes(5, b, 7))

Øvelse 6: Funksjon + løkke Gjenstår

Eksamen 2021, oppgave 1b. Bruk panteautomat i ei for-løkke: små flasker fast på 12, store 5, 7, …, 23. Kall funksjonen for hver verdi og skriv ut svaret.

Første svar: 39 · Siste svar: 93
Hint 1 – hva står fast?

Små flasker = 12. Lag en variabel for det før løkka, akkurat som sma = 8 i oppvarmingen.

Hint 2 – hva endrer seg?

De store flaskene, så de skal i for-linja. Det er nøyaktig samme range som i øvelse 4.

Hint 3 – hva skjer inni løkka?

Kall panteautomat(?, ?) og bytt ut ? med navnene på variablene, ikke faste tall: først variabelen for små flasker, så variabelen fra for-linja. De to linjene med resultat = … trengs ikke.

Hvorfor forrige forsøk ikke virket

range(12, 3) starter på 12 og skal stoppe før 3 – da blir det null runder. Og a finnes bare inni funksjonen, så panteautomat(a, 3) utenfor ville krasjet.
